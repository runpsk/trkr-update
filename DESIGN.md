# Design context

- Product: Thai-language TalesRunner Korea update archive.
- Visual direction: editorial game-news page; violet/pink brand gradient, clean white cards, restrained shadows, rounded tables, and compact Korean source labels.
- Typography: Kanit for Thai readability, with system fallbacks. Body copy stays light-to-regular; headings use medium/semi-bold.
- Layout: 1080px reading column, sticky pill navigation, responsive cards and horizontally scrollable data tables.
- Behavior: preserve light/dark color-scheme support, visible keyboard focus, lazy-load editorial images, and keep table labels translated into Thai.
- Content pattern: Thai title first, Korean original directly below, explicit event periods, red warning notes, and official-source attribution.
